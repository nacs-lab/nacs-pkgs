NaCs packages

Built from nacs-lab/nacs-pkgs. Add the repository to /etc/pacman.conf to use it.

The packages and the databases are signed with the key FB3383FB18F0EC34A1ABC3D275A6768C2AA33C49. Import it before using the repository with

curl -O https://nacs-lab.github.io/nacs-pkgs/nacs.asc
pacman-key --add nacs.asc
pacman-key --lsign-key FB3383FB18F0EC34A1ABC3D275A6768C2AA33C49

After adding the repository, install nacs-keyring to keep the key up to date.

pacman -Sy nacs-keyring
